# 🐾 Лапка Добра — Telegram-бот

Бот-вход в волонтёрский конструктор: заявка в команду, приём идей, лапки,
уровни, «Лапка дня» и модерация для координаторов.

Сделан на **grammY + TypeScript**, данные — в локальном JSON-файле.

---

## Быстрый старт

```bash
cd bot
npm install
copy .env.example .env
```

Заполни `.env`:

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен из @BotFather |
| `ADMIN_IDS` | Telegram ID координаторов через запятую |
| `CONTACT_URL` | ссылка на координатора |
| `SITE_URL` | сайт проекта |
| `DOBRO_URL` | ссылка на Добро.ру |
| `TIMEZONE` | часовой пояс для «Лапки дня» |

Запуск:

```bash
npm run dev
```

Проверка типов:

```bash
npm run typecheck
```

---

## Как получить токен и ID

1. Открой **@BotFather** → `/newbot` → имя и username → получишь `BOT_TOKEN`.
2. Свой Telegram ID узнай у **@userinfobot** — вставь его в `ADMIN_IDS`.
3. Аватар бота: @BotFather → `/setuserpic` → загрузи `bot/assets/avatar.png`.

## Что умеет бот

**Меню (баннер + кнопки):**
🐾 Регистрация в команду · 💡 Предложить идею · 🗂 Банк идей · 🧭 Направления ·
📅 Ближайшие дела · 🏅 Мои лапки · 🎯 Лапка дня · 📚 Как это работает ·
🛍 Мерч · 🛡 Правила и безопасность · ✉️ Связаться.

**Регистрация в команду.** Роль → имя → возраст → направление → подтверждение.
Для 14–17 лет бот **требует документ согласия родителей** (фото или файл) —
без него заявку нельзя одобрить. Заявка уходит координаторам с кнопками
«Одобрить / Доработка / Отклонить». После одобрения начисляется 10 лапок.

**Идеи.** Пять вопросов (название, что, для кого, зачем, что нужно) → идея
попадает в банк и к координаторам. Дальше статусы: на разборе → команда →
в работе → реализовано. За принятую в команду идею автору начисляется 25 лапок.

**Лапки и уровни.** Работает то же правило, что на сайте: лимит **100 лапок в
неделю** на уровне данных, уровни нельзя купить, начисления за действия
прозрачны. «Лапка дня» даёт 3 лапки после подтверждения координатором.

**Профиль.** Уровень, лапки, прогресс до следующего уровня, серия без пропусков,
статус заявки и направление.

**Админка** (`/admin` или кнопка в меню для админов): сводка, очередь заявок,
идеи на разборе, начисления на проверке. Решения принимаются кнопками прямо
в уведомлениях.

**Команды:** `/start`, `/menu`, `/help`, `/admin`.

---

## Правила, которые бот соблюдает

- 14–17 лет — только с документом согласия родителей.
- Лапки нельзя купить, обменять или передать; лимит 100 в неделю.
- Уровни только зарабатываются.
- Реклама и сборы денег — вне бота.
- Спорные случаи решает координатор.

## Структура

```
bot/
  src/
    index.ts          # точка входа, проверка BOT_TOKEN
    handlers.ts       # маршрутизация диалогов
    registration.ts   # заявка в команду + согласие родителей
    ideas.ts          # приём идей и банк идей
    profile.ts        # профиль, «Лапка дня», инфоразделы
    admin.ts          # модерация
    storage.ts        # JSON-хранилище и правила лапок
    levels.ts         # уровни, направления, тарифы
    texts.ts          # все тексты
    keyboards.ts      # клавиатуры
    state.ts          # состояние диалогов
    notify.ts         # уведомления админам
    helpers.ts        # баннер и меню
  assets/
    banner.svg/png    # баннер для меню
    avatar.svg/png    # аватар для @BotFather
    render.mjs        # рендер SVG → PNG
  data/db.json        # создаётся автоматически
```

## Данные

`data/db.json` создаётся при первом действии. Удалить файл — сбросить базу.
Для production данные переносятся в Supabase по схеме из `../supabase/schema.sql`.

## Замечание про картинки

Баннер и аватар собраны как SVG и отрендерены в PNG локально (`sharp`), поэтому
кириллица на баннере чёткая. Исходники лежат рядом — можно править текст и
перерендерить:

```bash
node assets/render.mjs assets/banner.svg assets/banner.png 1280 640
node assets/render.mjs assets/avatar.svg assets/avatar.png 512 512
```
